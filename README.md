# Hi, I'm Giovanni

I'm finishing my MSc in Computer Science, with a focus on machine learning and data. I like problems where a claim can be tested, and I care about testing it properly: a validation set that is really only used for tuning, a comparison that is fair to the baseline, a result that comes with its limits.

My projects range from data pipelines and NLP to reinforcement learning, planning with LLMs, computer vision and quantum optimization. Most of the code and notebook text is in Italian; the READMEs are in English.

## Selected work

| Project | What it is |
|---|---|
| [**SNM_Project**](https://github.com/GiovanniLodari/SNM_Project) | End-to-end pipeline on Mastodon: data collection, four synthetic-text detectors, LLM-based fact-checking, and diffusion analysis (community detection, influence maximization, Monte Carlo simulations). FastAPI + React interface, with tests. |
| [**Leduc-Poker-RL**](https://github.com/GiovanniLodari/Leduc-Poker-RL) | Reinforcement-learning experiments on Leduc Poker with OpenSpiel: NFSP against DQN, CFR and Deep CFR, exploitability, network variants and an Alpha-Rank tournament. |
| [**PDDL_LLM**](https://github.com/PaoloPangallo/PDDL_LLM) | With [Paolo Pangallo](https://github.com/PaoloPangallo). A LangGraph agent that turns a story into PDDL, validates it with Fast Downward and repairs it with an LLM reflection step. |
| [**MCP_E-commerce**](https://github.com/PaoloPangallo/MCP_E-commerce) | With [Paolo Pangallo](https://github.com/PaoloPangallo). An AI shopping assistant built on MCP, agentic workflows and retrieval, with a FastAPI backend and a React interface. |
| [**ProgettoBD**](https://github.com/GiovanniLodari/ProgettoBD) | Streamlit + PySpark app to explore large collections of disaster tweets: SQL editor, charts and distributed ML. |
| [**ProgettoIngSW**](https://github.com/GiovanniLodari/ProgettoIngSW) | Company organigram manager with a Spring Boot backend and an Angular frontend. |
